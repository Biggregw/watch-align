Watch Align V1 1.1.0 separates visual alignment confidence from perspective-dependent measurement reliability.

A strong overlay is no longer labelled low simply because an ellipse-based perspective estimate is large. The app now reports Visual alignment confidence, Perspective suitability, and Measurement reliability separately. Perspective distortion can withhold bezel/date precision without downgrading otherwise strong dial/marker registration.

The former Apparent camera tilt label is now presented as a Perspective distortion estimate because it is an ellipse-equivalent image-geometry estimate, not a calibrated physical camera angle.

For Rolex GMT-Master II 126710BLNR, Watch Align now knows the official Rolex source pages for both current bracelet variants: m126710blnr-0002 (Jubilee) and m126710blnr-0003 (Oyster). Official stock assets are fetched and cached locally from Rolex on demand with source URL, model code, variant and SHA-256 provenance. Rolex image files are not redistributed in this public repository.

Existing V1.0 reference data remains local. V1.0.0 remains available as a rollback release. Measurements remain image-geometry diagnostics rather than physical metrology or proof of authenticity.
