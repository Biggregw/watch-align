# 12-marker projected-reference diagnostics

The 12-marker inspection screen now overlays a fixed perspective-projected genuine-reference triangle in cyan and the operator-corrected candidate marker in green.

It also reports displacement in reference base-width (BW) units:

- base radial offset: positive means outward/toward the minute track
- apex radial offset: positive means outward/toward 12 o'clock
- width delta: candidate width relative to projected reference width
- centre lateral offset: candidate base centre left/right relative to the projected reference
- left and right base-corner radial offsets
- rotation from the production triangle metric

These are photographic QC measurements against an image-derived reference, not Rolex CAD, manufacturing tolerances, or an authenticity determination.

Current interim GMT control medians used for explanatory wording are base-to-60 0.123 BW and apex-to-crown 0.237 BW. Frozen classification ranges remain unchanged pending a larger independent control population.
